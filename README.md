# Welcome to Skardi demo respository!

You can checkout the demo under expense_reimbursement/, where we put a comparison of setting up an multi-role expense reimbursement pipeline using both the traditional approach and Skardi's approach, see the difference yourself!

There is also a demo under multi_calendar/ — a read-only calendar app that unifies Google Calendar and Feishu Calendar into one skardi-served week view: skardi fetches both sources through an Open Connector gateway, materializes them into local SQLite, and serves the frontend with zero custom backend code.
